# Renamed Web Development Project

Files were renamed according to their visible page content, and local filename references in HTML/CSS were updated.
The old `.git` directory was intentionally excluded so this project can be added to the new GitHub repository without carrying the previous repository history.

## New structure

- `01-html-fundamentals/` — HTML examples, forms, lists, layout, and portfolio
- `02-css-fundamentals/` — CSS demos and stylesheets
- `03-wolfclothing-store/` — multi-page clothing catalogue project and images
- `04-homework/` — pizza order form, seminar timetable, and other practice media
